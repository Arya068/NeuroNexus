
This project is A simple and clean Web Form designed to collect User Information( inspired by the layout of Google Forms) It is built using only HTML5 and CSS3.

✨ Features

- Google Forms-like design
- Pure HTML & CSS (no JS)
- Fully responsive layout
- User-friendly and accessible
- Required field validation using HTML5
- Subtle hover and box-shadow effects for better UI

 📋 What the Form Collects

The form collects the following information:

- Full Name (Text Input)
- Contact Number (Phone Input)
- Address (Multiline Textarea)
- Company Name (Text Input)
- Email Address (Email Input)
- Department (Dropdown: HR, Sales, Development, Marketing, Others)
- Gender (Radio Buttons: Male, Female, Prefer not to say)
- Submit Button

All essential fields are marked as **required**, so users can’t submit incomplete forms.

 💡 Styling Highlights

- A soft blue background for the page to create a calm, professional feel.
- A white, card-like form container with rounded corners and a minimalistic box shadow to lift it off the page.
- Smooth hover effect on the Submit button with a slight scale for interaction feedback.

🚀 How to Use

1. Download or copy the code into an `.html` file.
2. Open it in any browser(e.g., Chrome, Firefox, Edge).
3. You’ll see a functional form ready to collect input.
4. Since there’s no backend connected, form submissions won’t be stored—this is only the front-end part.
